# OpenAPI Specification texts

The OpenAPI Specification 3.0.4, 3.1.1, 3.1.2 and 3.2.0 (`versions/*.md` of `main`, ffb3e579, of the
OpenAPI Initiative's [OpenAPI-Specification](https://github.com/OAI/OpenAPI-Specification)
repository), copied unchanged and licensed under the Apache License 2.0 (see `LICENSE`).

`SpecificationExamplesTest` reads its normative examples as test vectors: the Style Examples table
of every version, and the Parameter Object examples of 3.2.0 with their `dataValue` and
`serializedValue`.
